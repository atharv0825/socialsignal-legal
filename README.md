
# SocialSignal Legal

Public legal pages for SocialSignal, an AI-powered social media opportunity discovery platform.

## Pages

- **Privacy Policy:** Published through GitHub Pages at the repository's configured public URL.

## Deployment

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Click **Save**.
6. Wait for GitHub Pages to publish the site.

The privacy policy is served from `index.html` in the repository root.
